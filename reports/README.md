# Verification evidence

`playwright/index.html` is the checked-in HTML report from the latest successful `npm run test:e2e` run. The command regenerates it from a clean checkout; traces remain available in `test-results/` only when a test fails.

`profiling.json` is generated by `npm run profile`. It captures a Chromium production-preview benchmark with a 180-second game configuration and five start/leave memory cycles. The report records the browser, viewport, frame-time statistics, maximum observed entity count, available JavaScript heap readings, and whether the match reached a result screen.
