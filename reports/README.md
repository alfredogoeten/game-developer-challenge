# Verification evidence

`playwright/index.html` is the HTML report from the latest `npm run test:e2e` run: **101 passed, 5 skipped** across desktop and mobile Chromium. `playwright-failure-traces.zip` preserves the 11 visual failures from the preceding run, including expected, actual, and diff screenshots and Playwright traces. The command regenerates the HTML report; visual baselines in `e2e/visual.spec.ts-snapshots/` remain versioned separately.

`profiling.json` is generated by `npm run profile`. It captures a Chromium production-preview benchmark with a 180-second game configuration and five start/leave memory cycles. The report records browser, CPU, available GPU, viewport, DPR, frame intervals, FPS, simulation and renderer time, entity count, forced-GC heap readings, teardown resource state, and whether the capture is valid and eligible for the visible-browser reference target. `npm run profile -- --headless` is diagnostic only.

The checked-in capture reflects the 100 HP / six-enemy balance and is a valid three-minute **headless** diagnostic on Chromium 153, 1440x900, DPR 1, AMD Ryzen 5 3600, and SwiftShader. It reports **32.96 FPS** and **33.40 ms p95**, so it is not eligible for the visible desktop reference target. Simulation and renderer synchronization average 0.040 ms and 0.022 ms per frame, respectively, with 11 maximum simultaneous entities. Every teardown reports zero canvases, battle instances, input controllers, and tickers. Forced-GC JavaScript heap grows from 3.48 MB before cycles to 6.90 MB after five cycles, with growth on every cycle; this remains an observed Chromium/PixiJS memory limitation to inspect in the visible reference browser before release. The measured main-thread simulation and synchronization work is small relative to the 33.40 ms frame p95, so the remaining frame delay is in rendering, GPU/SwiftShader, scheduling, or another unmeasured part of the frame. The report does not assign an unsupported share to any of those causes.

Playwright additionally checks immediate Options persistence and failed-write retry, 100 HP and the separate 12/25 damage rules, the six-enemy spawn timer freeze, responsive pagination and invalid page-size responses, mobile scrolling and button reachability at 320×568, 667×375, and 851×393, and visual baselines for visible `+`/`−` icons, red full/partial ship bars, the centered HUD, touch controls, and results.
